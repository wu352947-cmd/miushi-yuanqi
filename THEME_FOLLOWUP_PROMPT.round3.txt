第二轮：按审阅结论融合「懒大王·粉色蔷薇」主题的配色与气质（只借 token 和气质，不直译酒馆结构），并美化底部导航。参考：ref/rose-theme.css、ref/preview/index.html 的 B/C 栏（适配版）。

零、质感参考（最高优先级）：芴发来 5 张主流人机恋 app 截图 ref/ins/chat.jpg, home.jpg, nest.jpg, together.jpg, mine.jpg，请先逐张查看。芴喜欢它的"ins 风通透感"：极薄磨砂玻璃（背景几乎透明、壁纸清晰透出）、一圈白色高光细边、圆润胶囊/大圆角形状、灰蓝/柔灰细字、细线图标、底部导航中间圆形 Memory 珍珠扣式按钮。只学这种质感与组件气质，不要照搬它的布局、文案、图片、角色或英文字样；我们的结构、宋体、粉/冰蓝主题和壁纸分配保持不变。全局卡片、气泡、顶栏、输入框、底部导航、列表项都统一成这种通透玻璃质感。

一、主题 token
- 粉色默认：--pink:#E4A4B2; --pink-light:#F7E0E6; --lace:#FDF8FA; --text:#554B5A; --text-2:#968C9B; --quote:#8F5A5A; --italic:rgba(75,75,75,.49)。
- 冰蓝：--pink:#7BA8C4; --pink-light:#D7E8F2; --text:#4A545E; --text-2:#8A96A0; --quote:#5A7A8F。
二、聊天气泡（左右对话保持）
- 芴明确反馈：上一版气泡"不够通透"、太白太实。气泡必须通透，能隐约看见壁纸纹理（像磨砂玻璃/薄纱），这是本轮第一优先级。
- AI 左：background rgba(255,255,255,.34)~.42 + backdrop-filter: blur(14px) saturate(1.25)（带 -webkit- 前缀），1px 半透明白描边 rgba(255,255,255,.65) 作玻璃高光边，外加极淡主色投影 0 4px 16px rgba(主色,.10)；可加一层很淡的从左上到右下的白色渐变高光（.18→0）。圆角 18px 18px 18px 6px。
- 用户右：粉 rgba(250,214,224,.46) / 冰蓝 rgba(200,222,238,.46)，同样 blur+saturate 与白高光边，圆角 18px 18px 6px 18px。
- 不要实心白底、不要双虚线/蕾丝描边、不要厚阴影。文字可读性靠模糊与轻微 text-shadow(0 0 1px rgba(255,255,255,.6))，在 wp13/wp12 上截图自检，确保既通透又可读。最大宽 ~80%；宋体 14.5–15px，行高 1.75。
- 顶栏、输入胶囊、底部导航、工具步胶囊同样采用这种通透磨砂质感，整体统一。
- em 用 --italic；引号「」用 --quote；u 用主色 1.5px 底边。时间戳 10.5px 霜面小胶囊。头像 36px 圆，白边 1.5px + 主色环 1.5px + 轻阴影。
- 输入：霜面胶囊，边 1.5px --pink-light，发送 36px 主色圆钮 + 白箭头（CSS/SVG）。工具步/思考用克制的浅主色胶囊，文案「思考中」「检索记忆 · 0.4s」，不要 emoji 串。
三、底部导航美化（重点，芴觉得纯文字太单调）
- 每个标签配一枚自绘细线 SVG 图标（线宽 ~1.4，圆角端点，与宋体气质一致）：聊天=信封或对话气泡带小心形、记忆=带蝴蝶结的日记本/书签、一起听=黑胶或音符、我的=小花框头像/蕾丝圆。图标在文字上方，文字 10.5px 宋体。
- 导航本体是悬浮的霜面胶囊（离底 ~12px，左右留白，圆角 24px，细发丝描边，极淡内阴影），顶缘可有一道极细的蕾丝/珍珠点线装饰（CSS 圆点或 SVG，透明度低）。
- 选中态：图标与文字变主色，图标下方或背后出现一颗小珍珠/小爱心/小蝴蝶结标记，轻微上浮 1–2px，过渡 200ms；未选中用 --text-2。
- 中间「记忆」稍突出：略大的圆形霜面底座 + 主色细环（像一枚珍珠扣），但不要做成夸张的凸起大按钮。
- 两套主题都适配；尊重 prefers-reduced-motion。
- 顺带检查其他页面里是否也有"只有文字"的单调组件（例如我的页列表项、设置项、记忆分类 chip），同样配细线小图标或小点缀，保持克制统一。
