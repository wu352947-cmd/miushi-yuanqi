## 1. 玻璃要通透，不要厚塑料感
目标参考：ref/glass-target-our-tide.jpg（冰蓝海面壁纸上的一组卡片：Our Tide 大卡、时钟方卡、两个胶囊、留言卡、底栏）。只学「玻璃的物理质感」，不抄它的布局、文字、头像或图标。
她的原话大意：参考图的组件透明感强很多，可以美观地透视背景，又不影响文字清晰，整体高级；我们的玻璃做厚了，看不到背景的主题颜色，像塑料。

请做到：
- 卡片底色变薄：现在的乳白填充太实，改成很低的白色填充（大约 0.10–0.22 的不透明度区间里按卡片类型取值），让壁纸的颜色和形状能透出来。
- 模糊变轻并带一点饱和度：backdrop-filter 用较轻的 blur（约 10–18px）加 saturate(1.3–1.6)，必要时轻微 brightness，让透出来的是主题色（冰蓝透蓝、粉色透粉），不是灰白。
- 轮廓靠光不靠厚度：1px 半透明亮边（上亮下淡的渐变边），顶部一条很淡的高光反射，内侧极淡的内阴影；外阴影要轻、要散，不要一圈灰色投影。
- 字的清晰度靠字本身：主文字用主题色系里足够深的颜色，加很淡的 text-shadow（浅色光晕或极淡深色），而不是把卡片底加厚。小字也要能看清。
- 分档透明度：大信息卡稍实一点，胶囊/时钟/小组件更透，图片卡几乎不加底；定义成几个 token（如 --glass-thin / --glass-regular / --glass-thick），全站统一使用，不要每处写死。
- 两套主题（粉色蔷薇、冰蓝）、所有页面（首页、聊天、记忆、一起听、我的、角色库、统计页、各弹层、底栏）都要改到，底栏也同样通透但图标清晰。
- 花哨壁纸（含之前提过的 wp02、wp14 这类密集壁纸）要单独检查：如果字看不清，只在那张壁纸上提高一档 token，或给文字区加局部更实的底，不要全局加厚。
- 手机性能：backdrop-filter 只放在卡片本体，不要嵌套多层；动画仍只用 transform/opacity；低端机（prefers-reduced-transparency 或检测到性能差时）退回稍实的半透明底。
- 不要回退：底栏 66px、四个图标齐平、记忆爱心不跳不凸出；「此刻」编辑布局不变。

## 2. 歌单封面用网易云原封面，不要占位图
- 把 src/data.js 里一起听 / 首页小卡 / 歌单里的假歌（平潭的风、门灯、围巾分你一半、海边邮局等）换成网易云上真实存在的歌。挑 6–10 首温柔、适合陪伴氛围的中文歌（民谣 / 独立 / 轻流行皆可），歌名、歌手、时长都必须和网易云一致。
- 每首歌记录网易云歌曲 id 和专辑封面地址（picUrl，p1/p2.music.126.net 开头）。用网易云公开接口自己查证，例如：
  - 搜索：https://music.163.com/api/search/get/web?s=<关键词>&type=1&limit=5
  - 详情：https://music.163.com/api/song/detail/?ids=[<id>]  （songs[0].album.picUrl、duration、artists）
  逐首确认 id 能查到、封面地址能打开（HTTP 200 且是图片）。查不到或打不开的歌就换一首，不要编造 id 或地址。
- 显示时用 picUrl 加 ?param=300y300（列表小图可用 ?param=120y120），由手机直接从网易云图片服务器加载，不经过我们的服务器。不要把封面图片打包进 dist。
- 唱片中心、正在听卡片、歌单列表、首页「一起听」小卡都用同一首歌的原封面；封面加载失败时退回一个和主题同色的素色唱片（不是假插画），不要出现破图标。
- 记忆、留言等文案里引用到旧假歌名的地方，同步改成新的真实歌名，保持语义通顺（例如「那首歌的前奏」这类描述可改写）。
- 如果 server/ 已有一起听或歌曲相关的数据结构/种子数据，同步加上可选字段 neteaseId、coverUrl，并补一条测试；没有就只改前端数据，不要在这一轮实现网易云播放或登录。
- 在 README/文档里不要写这些歌是谁挑的，只说明封面来自网易云并按歌曲 id 加载。

## 硬性验收：必须对着参考图严格比，不合格不准交
- 把 ref/glass-target-our-tide.jpg 和你改后的冰蓝首页截图拼成左右对比图（shots/phase-c1/compare-target-vs-ice-home.png），粉色主题首页也和参考图拼一张（compare-target-vs-pink-home.png）。用你的看图能力逐项对比，打分 1–5：

  2. 玻璃薄度：是否像薄玻璃而不是乳白塑料板
  3. 边缘与高光：细亮边、顶部反光是否精致自然
  4. 文字清晰：在通透的前提下，大字小字是否都清楚
  5. 层次：不同卡片透明度是否有区分，整体是否轻盈
  6. 整体美观与 ins 风：是否素雅、高级、像精心设计的 ins 风手机界面，而不是模板或 AI 感
- 任何一项低于 4 分就算不合格：继续改、重截图、重新对比打分，直到六项都至少 4 分为止。不要因为想早点结束就放宽标准，也不要在没改好的情况下写「通过」。

- 其他页面（聊天、记忆、一起听、我的、统计、角色库、弹层、底栏）也要用同样六项自查，至少写出每页的分数；明显比首页差的页面要改到同一水准。
