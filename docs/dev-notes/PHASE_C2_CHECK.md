## 零、结论

- 硬性数值全部达标：backdrop-filter `blur(3px / 4px / 6px)`、`saturate 1.05–1.10`、`brightness 1.05–1.06`；白色填充 `0.07–0.18`（上沿亮、下面透）；**没有全局雾层、没有径向大白光**；壁纸层只 `brightness(1.04) contrast(0.98)`，**不模糊**。
- 景物测试通过：冰蓝首页 4 张卡片内部能认出「水波纹 / 阳光波光 / 樱花五瓣花与花蕊 / 粉色花瓣边缘」；粉色首页能认出「粉色蝴蝶结丝带 / 蕾丝花边 / 爱心贴纸 / 红粉格纹丝带 / 活页环 / 手写体 dreamy girl」。
- C1 ↔ C2 并排一眼可见更透：同一张冰蓝壁纸下，C1 卡片后面是均匀蓝白，C2 能直接看见水面纹理与花瓣。
- 文字实测对比度：全站 140 个采样点最低 **3.5:1**（唯一一个是头像装饰字「芴」），正文 **4.68–8.41:1**、大数字 **6.11–8.41:1**；16 个页面 × 主题的最低值全部 ≥ 3.5，绝大多数 ≥ 4。
- 回归断言 **41 / 41** 通过；`pytest` **48 passed**；截图 **0 条 JS 报错**；`node scripts/build.mjs` 通过。

## 二、首页壁纸：逐张看过之后的选择

**结论：冰蓝首页用 `wp09`（水面波光 · 樱）；粉色首页用 `wp05`（白桌面 · 粉色蝴蝶结 / 爱心 / 蕾丝）。两张都来自芴自己的 `assets/wallpapers-720/`，没有自绘、没有引用任何外部图片。**

对比过所有候选（截图见 `shots/phase-c2/_cand-*`，最终选型记录）：

| 壁纸 | 看到的东西 | 结论 |
| --- | --- | --- |
| wp09 水面波光 · 樱 | 水波纹、阳光波光、樱花五瓣花 | **冰蓝选它**：浅色干净、景物最具体；C1 冰蓝首页也是 wp09，沿用同一张，C1↔C2 并排的差异就只来自玻璃而不是换壁纸 |
| wp10 冰蓝置物架 · 大耳犬 | 物件轮廓太淡，放大后只能猜 | 透明玻璃下认不出具体物件，不用 |

| wp05 白桌面 · 粉蝴蝶结 | 粉色蝴蝶结丝带、爱心贴纸、蕾丝、花瓣、圆规、杯子 | **粉色选它**：现有库里唯一有**真实淡粉色**且有大量可辨物件的一张 |
| wp01 / wp13 | 粉格纹 + 小兔 / 小羊，但整体近白（平均饱和度 1–2/255） | 一上透明玻璃就被洗成白色，不满足「粉色不能被洗成白色」 |

- 底栏：`--glass-thin`（.13→.07、3px 模糊）通透；底栏下正文用 mask 淡出（`to top, transparent 0 → .12 18px → .55 46px → #000 84px`），**底栏本身没有加厚**；高度 66px、四图标顶部 spread 0、记忆爱心 26×26。
