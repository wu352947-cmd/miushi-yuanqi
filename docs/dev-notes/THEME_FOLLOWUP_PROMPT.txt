第 4 轮：苹果式玻璃质感 + 色调统一 + 首页小组件化（芴不满意上一版，认为"看得出 AI 感"）

【总原则：所有参考图只学质感（玻璃材质、透明度、高光、圆角、字重、色调协调方式、组件多样性），绝不照抄布局、文案、图标造型、图片或角色。结构和内容是缪诗鸳杞自己的。】

先用图片读取工具逐张看 ref/ins/home.jpg、chat.jpg、together.jpg、nest.jpg、mine.jpg（质感目标），再看自己的 shots/pink-home.png、pink-chat.png 对比。只学质感、配色方法、组件多样性，不照搬布局、英文文案、图片和角色。

一、色调统一（最重要）
参考图整页只用一个色系：壁纸、玻璃、文字、图标、按钮全是同一种浅蓝灰的深浅变化，所以协调。我们上一版是粉白格子壁纸配深紫字和偏红按钮，颜色散。
- 每个主题只定义一个主色相，所有颜色都从它派生（同色相、不同明度和饱和度）。粉色主题：玫瑰灰粉系，正文用低饱和的灰玫瑰褐（约 #6E5A62），次要字 #A8959C，强调色 #D39AA8，发送按钮等用同色系柔粉渐变，不要偏红偏紫的深色块。冰蓝主题：雾蓝灰系，正文 #4F6372，次要 #8FA2AF，强调 #8DB4CC。
- 图标、分隔线、进度条、时钟指针全部用这个色系，禁止出现色系外的颜色（在线状态点也用主色）。
- 给每页壁纸叠一层同色系的极淡雾化渐变（顶部和底部更浓），让壁纸和玻璃融为一体。

二、苹果 Liquid Glass 式玻璃
- 卡片/气泡/导航/输入框：background 用同色系白色的 linear-gradient（上 rgba(255,255,255,.55) → 下 rgba(255,255,255,.22)），backdrop-filter: blur(24px) saturate(1.6)（带 -webkit-）。
- 1px 内高光：box-shadow: inset 0 1px 0 rgba(255,255,255,.85), inset 0 -1px 0 rgba(255,255,255,.25), 0 8px 24px rgba(主色,.12)；外边框 1px rgba(255,255,255,.6)。
- 大圆角：卡片 24–28px，胶囊控件 999px，气泡 20px（尾角 8px）。
- 字体：中文标题保留思源宋体，但字重轻（400/500），数字和小标签用细的 sans（-apple-system, "SF Pro", "PingFang SC"），字距略开。字号层级清楚：大数字 40–48px 细体，正文 15px，标签 11px 大写字距 .12em。

三、首页改成多样的小组件（AI 感最重的地方）
上一版首页只有标题+按钮，空洞。改成可滚动的小组件网格，尺寸形状各异（参考 home.jpg 的思路，但内容用我们自己的）：
1. 大卡（整宽）：两个圆形情侣头像（我/缪诗）重叠、「在一起 第 N 天」大细数字、一行小诗句、since 日期。
2. 方形卡（半宽）：模拟时钟表盘（SVG 刻度+时分秒针，实时走动）+ 星期日期。
3. 两个胶囊卡（半宽竖排）：「欢迎回家」问候 / 天气（图标+温度+城市，假数据）。
4. 整宽留言卡：缪诗留的一句话 + 时间 + 细线图标操作（喜欢/回复/收藏）。
5. 一起听迷你播放卡：圆形唱片缩略、歌名、进度条、播放按钮。
6. 小组件：记忆胶囊（今日记住了什么）、时间胶囊入口、每日一句。
各卡片大小交错，间距 12px，像 iOS 小组件页。顶栏：左菜单线图标、中间玻璃胶囊页面名、右头像。

三点五、「分框摆放」的组件化（芴强调，硬性要求；参考 ref/ins/home2.jpg、nest2.jpg 的思路，只学质感不照抄）
- 每个功能都装在独立的玻璃框里，像 iOS 主屏小组件 + App 图标：尺寸形状多样（整宽大卡、半宽方卡、竖排胶囊、2×2 方形功能图标格、长胶囊签名条、拍立得式照片卡、唱片小组件），彼此留 12px 缝，壁纸从缝隙和玻璃里透出。
- 首页下半部分加一块「小功能格」：2×2 或 2×3 的方形玻璃图标按钮（细线图标 + 下方小字），功能用我们自己的：时间胶囊、每日一签、纪念日、一起读、留言板、心情日记等（无功能的可点开占位页）。
- 底部 tab 仍为 聊天 / 记忆（中间）/ 一起听 / 我的，不新增 tab。
- 一起听、记忆、我的页也按分框思路：功能分成多个大小不一的玻璃块，不要一整张长列表。
- 玻璃要和壁纸配合：玻璃色从壁纸主色取样，透明度足够看清壁纸纹理，像苹果 UI。

四、其它页同样去 AI 感
- 聊天：气泡用上面的玻璃；顶栏为玻璃条（返回、头像、名字、在线、右侧线图标）。
- 一起听：大圆唱片（玻璃边+缓慢旋转，尊重 reduced-motion）、进度条、三个控制按钮（中间玻璃圆播放键）、歌单列表做成一张大玻璃卡内的细分隔行。
- 记忆、我的、设置：列表都放在大玻璃卡里，每行左侧细线图标，右侧箭头，分隔线用主色 10% 透明度。
- 底部导航：整宽贴底的玻璃底栏（顶部圆角 28），四个细线图标+小字，中间「记忆」是凸起的玻璃圆按钮（心形或书签线图标），选中态只用主色加深，不加额外装饰物。

四点五、聊天页重点参考 ref/ins/chat2.jpg（芴新发，聊天页以它为准）
- 气泡是带一点灰的磨砂玻璃（同色系灰调白，约 rgba(235,238,242,.55) 再加 blur），壁纸清晰透出，气泡宽、圆角大、行距舒展（line-height 1.75），多段文字在同一气泡内分段。
- AI 气泡上方的工具调用做成玻璃胶囊条「⚙ 使用了 1 项工具 ›」（用细线扳手图标，不要 emoji），点开展开步骤。
- 气泡底部可以有一条细分隔线加一行灰色小字批注（例如内心旁白，使用斜体与 italic 颜色），再往下一行极小的灰色统计（如 ↑2 · 本轮 tokens 等，假数据）。
- 顶栏：左返回圆玻璃按钮，中间圆头像与名字 ›，右侧玻璃胶囊按钮和通话线图标。
- 输入栏：左 + 圆玻璃按钮，中间玻璃长胶囊输入框，右侧语音波形线图标，发送为纸飞机线图标。
- 仍保持我们的主题色系，不照搬它的图片、表情包和文案。

四点六、token 统计（芴明确要求）
- 每条 AI 回复气泡下方一行极小灰色统计（10.5px，次要字色，细 sans），格式参考 chat2.jpg 底部：「↑ 输入 2,481 · ↓ 输出 312 · 本轮 2,793 tok · 1.8s」，可再加本会话累计。
- 数据结构按 OpenAI 兼容接口的 usage 字段（prompt_tokens / completion_tokens / total_tokens）设计，写成 renderUsage(usage, ms) 函数；现在是样稿，用假数据填充，但留好接口，README 说明以后接真实 API 时从响应的 usage 读取。
- 「我的」或设置页加一张小卡：今日 / 本月 token 用量（细数字 + 细线迷你柱状图，假数据）。

四点七、移动端性能（芴明确要求：运行不能卡顿，必须做移动端性能适配）
目标：中端安卓/iPhone 上打开、滑动、切页、切主题都流畅，不掉帧、不卡顿。验收时用 Chrome 手机视口（390×844）跑一遍，控制台无卡顿警告。
- 壁纸：不要一次性解码全部 17 张。只加载当前页+当前主题的那一张，其它按需加载；切页预加载相邻页。已内联的用 CSS background 单张切换，不要把多张同时放到 DOM。
- backdrop-filter 很重：只加在可见的卡片/导航/气泡上，模糊不超过 20px；同屏玻璃层尽量少（列表用一张大玻璃包住，不要每行一层 blur）。低端机或 prefers-reduced-transparency / 省电时降为半透明实色、去掉 blur。
- 动画只用 transform 和 opacity，时长 ≤ 250ms，加 will-change 仅在动画期间。时钟用 rAF，离开首页或页面 hidden 时立刻停。唱片旋转用 CSS，尊重 prefers-reduced-motion。
- 滚动：各页独立 overflow-y: auto + -webkit-overflow-scrolling: touch；避免整页重排；长列表用 content-visibility: auto。禁止在 scroll 里读布局再写样式。
- 触控：点击区域 ≥ 44px，去掉 300ms 延迟（touch-action），按钮按压缩放不要引起布局抖动。安全区用 env(safe-area-inset-*)，高度用 100dvh。
- 禁止：每帧改 DOM/innerHTML、同步 layout 循环、未节流的 mousemove/touchmove、巨大 box-shadow 叠多层 blur、循环里的模糊滤镜、启动时同步解析全部脚本阻塞首屏。脚本拆成初始化快路径，首屏先出壳再填数据。
- 构建后自测：无控制台 error；快速连切 6 个页面 + 两个主题各 3 轮，界面保持响应。README 写明性能策略。把「中端机流畅、无卡顿」列入主题验收第 6 条，不通过就改到通过。

六、主题一致性验收（必须通过才能输出 FINAL）
重新构建单文件 dist/index.html，截图两个主题全部页面（pink/ice 的 home、chat、memory、listen、me、settings、nav 特写、token 卡）。然后用图片读取逐张自查，并写 THEME_CHECK.md 逐页逐项打勾：
1. 色系：页面内所有颜色（字、图标、按钮、进度条、时钟、状态点、统计字）都属于该主题的单一色系，没有色系外的颜色、深色实心块或偏红偏紫按钮。冰蓝页没有残留粉色，粉色页没有残留蓝色。
2. 玻璃：卡片/气泡/顶栏/输入框/导航都是同一套玻璃 token（模糊、渐变、内高光、边框、投影一致），壁纸可见。
3. 字体与层级：一致的字重和字号层级，无突兀粗体。
4. 原创性：与 ref/ins 对照，确认没有照抄布局、文案、图标造型或图片。
5. 禁止项全部不存在。
